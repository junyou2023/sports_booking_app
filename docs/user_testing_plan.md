# User Testing Plan

## Objectives
Evaluate the overall usability of the sports booking application across key user workflows.

## Tasks
1. **Register and log in as a new user**  
   *Success criteria:* User creates an account and accesses the home screen without assistance.
2. **Search for nearby activities and apply filters**  
   *Success criteria:* User finds at least one activity matching search terms and filters.
3. **Book a slot and complete a mock payment**  
   *Success criteria:* Booking confirmation screen appears after payment simulation.
4. **As a vendor, add a facility and activity**  
   *Success criteria:* Newly created facility and activity appear in the vendor dashboard.
